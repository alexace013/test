1. Тестування сторінки /signup (Реєстрація)
Ціль:
Перевірити, чи правильно працює реєстрація нового користувача.
Кроки:
Перехід на сторінку /signup.
Заповнення форми реєстрації (email, пароль, підтвердження пароля).
Натискання на кнопку "Створити користувача".
Перевірка перенаправлення на сторінку логіну або /home після успішної реєстрації.
Перевірка помилок при неправильному введенні даних.

!!! Цей варіант тестування доступний при запуску Сypress та вибору файла для відтворення тесту: home.cy.js

---------------------------------------------------------------------------------

2. Тестування сторінки /login (Логін)
Ціль:
Перевірити, чи правильно працює логін для вже зареєстрованих користувачів.
Кроки:
Перехід на сторінку /login.
Заповнення форми для логіну (email, пароль).
Натискання на кнопку "Увійти".
Перевірка перенаправлення на сторінку /home після успішного логіну.
Перевірка помилок при неправильних даних (неіснуючий email, неправильний пароль).

---------------------------------------------------------------------------------

3. Тестування сторінки /home (Домашня сторінка)
Ціль:
Перевірити, чи доступна домашня сторінка тільки для авторизованих користувачів.
Кроки:
Перехід на сторінку /home без авторизації.
Перевірка перенаправлення на сторінку логіну для неавторизованих користувачів.
Авторизація через сторінку /login і перевірка доступу до сторінки /home.

---------------------------------------------------------------------------------

4. Тестування головної сторінки / (коректність перенаправлення)
Ціль:
Перевірити, чи коректно працює перенаправлення на домашню сторінку або на сторінку логіну залежно від статусу авторизації користувача.
Кроки:
Перехід на сторінку /.
Перевірка, чи буде перенаправлення на /home для авторизованих користувачів.
Перевірка, чи буде перенаправлення на /login для неавторизованих користувачів.
